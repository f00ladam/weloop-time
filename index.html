WeLoop / COROS 时间同步（多协议）

基于 Web Bluetooth，协议反编译自 WeLoop 官方 app。支持 V2 / V1 三代协议，可自定义蓝牙匹配名。

1. 蓝牙匹配

    默认 WeLoop。若选择框里看不到设备，改成 COROS、Tommy、Now 等，或勾选"列出所有"。

    2. 协议与参数

    时间取「当前时间 + 2 秒」以补偿传输延迟（与官方 app 一致）。
    含义未完全还原，默认全 0。byte18 填 ff(=-1) 则省略该字节。

    3. 连接并同步

    状态: 未连接
    「断开 / 取消配对」会依次执行：停止通知 → gatt.disconnect() → device.forget()（把设备从浏览器许可列表移除）。若系统蓝牙里仍显示已连接，多为系统蓝牙栈缓存或自动重连，请见下方说明。

    4. 日志

    说明 / 故障排除

    • 必须用 Chrome / Edge / Opera（安卓 Chrome 也行）。Safari、Firefox 不支持 Web Bluetooth。
    • 用 https:// 或 file:// 打开（直接双击本 HTML 即可）。
    • 安卓 Chrome：需 Android 6.0+ 且开启位置权限（BLE 扫描依赖）。
    • 连不上？先在系统蓝牙设置里忽略/取消配对该设备（Web Bluetooth 不能用已配对设备）。
    • 时间没变？断开蓝牙重连，部分固件要重连才刷新显示。
    • 不知道用哪个协议？先点「仅诊断」，日志会打印服务列表并判定 V1 / V2。
    • 点了断开但电脑仍显示连着？这是操作系统蓝牙栈的行为，不是页面没断。Web Bluetooth 的 disconnect() 只断 GATT 连接，底层 LE 链路可能被系统保留数秒；设备若配对过，系统还会自动重连。彻底断开需要在系统蓝牙设置里「删除设备」（Windows：设置 → 蓝牙和其他设备 → 该设备 → 删除设备），或在手表端关闭蓝牙。本页的「断开 / 取消配对」已自动尝试 device.forget()（Chrome 103+）。
